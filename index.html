Google Spreadsheet API

Masukkan URL Web App dari Google Apps Script untuk menyimpan data langsung ke Spreadsheet Anda.

Cara Setup Database Spreadsheet

  1. Buka Google Sheets baru.
  2. Klik Ekstensi > Apps Script.
  3. Hapus semua kode, lalu paste kode di bawah ini.
  4. Klik Terapkan > Deployment Baru > Pilih Aplikasi Web.
  5. Akses: Siapa saja, lalu Deploy. Copy URL-nya ke kolom di atas.
